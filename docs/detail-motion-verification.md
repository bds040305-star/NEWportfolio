키워드·이미지·본문을 새 내용으로 교체하지 않았다. 텍스트 루프는 원래 문구를 복제해 기존 상자 안에서만 움직이며 복제본은 접근성 트리에서 숨겼다. 글꼴·색상·간격·원본 레이아웃은 유지한다.

## 구현 방식

- 기존 GSAP을 재사용한다. LH에만 기존 vendor ScrollTrigger를 연결했다. 새로운 라이브러리나 제품 모델은 추가하지 않았다.
- 기존 페이지 스크립트가 타이틀·사진 opacity와 clip-path를 계속 관리한다. 새 카드 진입은 별도 CSS 이동값을 사용한다.
- Floating·패럴랙스·Hover를 개별 CSS 변수로 합성한다. 기존 GSAP의 transform과 직접 같은 값을 덮어쓰지 않는다. GSAP이 inline `translate:none`으로 초기화하는 경우에도 별도 합성 채널이 유지되도록 처리했다.
- 목업의 외곽과 화면을 같은 타이밍으로 움직인다. 화면·프레임 어느 쪽에 포인터나 키보드 초점이 있어도 자동 움직임을 멈춘다.
- 무한 루프와 Floating은 IntersectionObserver로 화면 밖에서 정지한다. 문서가 숨겨지면 일시정지한다. 별도의 지속적인 requestAnimationFrame 루프를 추가하지 않았다.
- 새 모션의 중복 초기화를 방지한다. 페이지 종료·설정 변경 시 자신의 관찰자·이벤트·GSAP 작업과 복제 요소를 해제한다. 기존 페이지의 이벤트나 Canvas 서명은 해제하지 않는다.
- `prefers-reduced-motion` 최초 설정과 실행 중 변경을 지원한다. 설정 전환 시 추가된 이동·복제 DOM을 제거하고 기존 페이지로 복원한다.
- 기존 색상 피드백이 즉시 바뀌는 작은 CTA에는 색상 전환을 부드럽게 적용했다. 이미 전환 효과가 있는 버튼은 보존했다.

## 회귀 검사 중 수정한 문제

1. 텍스트 복제로 키워드 상자의 고유 너비가 증가하던 문제: 원래 CSS 크기를 유지하고 실제 타일 너비를 기준으로 필요한 복제 개수를 계산했다.
2. Floating과 기존 GSAP의 inline transform 초기화 충돌: 독립 합성 채널로 분리했다.
3. 해비치의 기존 Hover가 작은 아이콘을 먼저 선택하던 문제: 해당 영역의 가장 큰 래스터 이미지를 선택하도록 수정했다. 새 모션에서 같은 이미지의 확대를 중복 등록하지 않는다.
4. 움직이는 목업이 새 쌓임 맥락을 만들면서 웨딩 목업 종료 버튼을 장식 SVG가 가리던 문제: 해당 배경 타원 2개의 포인터 처리를 제외했다. 그림과 배치 자체는 바꾸지 않았다. 수정 후 9개 목업을 실제 포인터로 다시 검사했다.
