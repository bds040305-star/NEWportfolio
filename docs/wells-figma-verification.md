## 용량

- 참조 PNG 원본 합계 **35,236,027 → 20,889,104 bytes**: 더 작은 무손실 WebP 38개를 실제 화면에 사용해 약 **40.7%** 절감했다. 원본 파일은 보존했다.
- 초기 공통 디자인 CSS **222,768 → 19,684 bytes**: 사용하지 않는 규칙 3464개를 제외했다. 텍스트 정밀 보정의 중복 선택자도 병합했다.
- HTML/CSS/JS 합계: 이전 HTML **37,998 bytes**, 새 구현 **512,945 bytes**. 17개 원본 섹션과 정밀 레이어를 구현해 코드는 증가했다. 코드 자체가 이전보다 작아졌다고 주장하지 않는다.
- 새 `assets/wells` 폴더는 원본과 최적화본·폰트를 함께 보존해 **53,702,954 bytes**다. 화면 전송량 절감과 저장소 디스크 사용량은 구분한다.
- 이미지 지연 로딩·비동기 디코딩을 적용했다. 실제 사이트 iframe과 그 안의 기존 Three.js는 체험을 시작할 때만 불러온다. 포트폴리오에 별도 제품 Three.js·모델은 추가하지 않았다.

## 한계·추가 자료가 필요한 부분

1. Figma의 제품 분해도는 단일 PNG다. 현재 구현은 원본 그림 영역을 움직이는 **2D 프레젠테이션**이며, 독립 부품의 정확한 내부 구조·가려진 면까지 재현하는 분해 조립은 아니다. 이를 위해서는 원본 부품별 레이어나 실제 제품 GLB/CAD가 필요하다. 기존 퍼블리싱의 Three.js도 실측 모델이 아닌 시연 모델이라고 명시되어 있어 포트폴리오의 새 제품 모델로 복사하지 않았다.
2. 오늘의 관리·성장 일지·사진 기록·My Page는 공개 사이트에 해당 라우트가 없어 로컬 Figma 체험으로 유지했다. 서버 저장·실제 기기 제어 기능은 제공하지 않는다. 사진·기록은 현재 페이지에서만 유지한다.
3. 회원가입·비밀번호 재설정·로그인·상담은 기존 퍼블리싱이 제공하는 범위의 체험이다. 실제 계정 인증·기기 연결·실제 AI 서비스까지 검증했다고 표시하지 않는다.
4. 모든 설명용 화면의 모든 작은 장식 버튼에 별도 서비스를 구현한 것은 아니다. 위 표의 주요 동작과 체험 경로를 검증했다.
