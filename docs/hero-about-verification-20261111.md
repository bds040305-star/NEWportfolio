# HERO / ABOUT ME / DASOM 로고 바 복원 검증

기준 커밋 `15169d2` 및 Figma `KfB1mAAYU0iBZAlCW5S4lI`의 메인 페이지를 비교했다. 제공 URL의 `310:5739`는 푸터였으므로 페이지 메타데이터로 HERO `310:5723`, ABOUT ME `310:5553`, 로고 바 `310:5531`을 찾고 각각의 디자인 컨텍스트와 스크린샷을 읽었다.

현재 main에는 ABOUT ME와 로고 바가 없었다. 사용자가 **Figma의 HERO·ABOUT ME·로고 바 모두 복원**을 선택한 뒤 해당 영역만 추가·복원했다.

## 구현 및 충돌 정리

- 기존 셔터/진입 타임라인은 그대로 유지했다. 과거 작업실 배경을 적용하던 `.studio::before/after`는 복원된 HERO에서만 비활성화했다. 예전 에셋과 타임라인을 삭제하지 않았다.
- HERO: 1920×1187, 원본 격자 배경과 다섯 콜라주/워드마크 에셋을 개별 배치했다. 모바일에서는 동일한 에셋을 화면 비율에 맞춰 배치한다.
- ABOUT ME: 1920×1518의 원본 좌표로 배경, 프로필 사진, 테두리, 소개/연락처/학력/자격증/수상/역량을 HTML로 구성했다. 모바일은 동일한 사진·문구를 읽을 수 있게 세로 흐름으로 배치한다.
- 제목의 Subway 폰트 파일은 로컬에 없으므로 **제목 텍스트 레이어만** Figma `download_assets`의 원본 PNG export로 사용했다. 접근성/문서 구조를 위한 같은 내용의 h1 텍스트를 유지했다. 전체 페이지를 캡처 이미지로 구현하지 않았다.
- 공통 헤더는 기존 DOM 하나를 유지한다. 원본 로고, 1920px에서 높이 100px/로고 82.775px/메뉴 위치 및 간격을 반영했다. ABOUT ME 시작점과 18px 메뉴 오프셋을 기준으로 0.4초 블러 전환한다.
- 이전 `chrome.js`의 헤더 클래스 변경 한 줄을 제거해 헤더 상태의 소유자를 하나로 통일했다. 해당 파일의 TOP·팝업·푸터 코드는 변경하지 않았다.
- 기존 body 클래스 감시기는 ScrollTrigger.refresh를 호출한다. 새 상태를 body에 추가하면 메뉴의 네이티브 smooth scroll이 끊어져, 새 상태는 html에 분리하고 변화가 있을 때만 갱신했다.
- 3D 모델/렌더러/포즈/드래그/후속 스크롤 안내 JavaScript는 원본과 동일하다. HERO의 라이브 모델 컨테이너는 Figma의 253×253 슬롯에 배치하고, ABOUT ME 위를 가리지 않도록 HERO 문서 위치에 둔다. 이후 섹션에는 기존 안내 레이아웃을 사용한다.
- 로고 바: 원본 #1b1b1b, 높이 203px, 상하 37px, 로고 129×129. 원숭이+텍스트를 묶은 6개 이상 항목과 동일 복제 트랙을 연결한다. 모든 항목은 하나의 트랙으로 왼쪽 26px/s 이동한다. 원본의 두 항목 유형 사이 간격은 사용자 요청에 맞춰 동일 피치 346.5px로 정규화했다.
- 트랙 끝의 gap을 너비 계산에 포함했다. Hover, 화면 밖, 비활성 탭에서 일시정지하고 reduced-motion은 정적으로 표시한다. 새 GSAP/Three 인스턴스를 만들지 않았다.
- 폰트는 `HeroAboutPretendard` 별칭으로 기존 폰트 파일을 재사용해 다른 섹션의 실제 폰트 선택에 영향을 주지 않는다.

## 실제 Chrome 검사

1920×1080, 2560/1440/768px 리사이즈, 390×844 모바일 터치에서 확인했다.

- 셔터 핸들 진입, HERO 블랙 헤더, ABOUT ME 블러 전환, 역스크롤 블랙 복귀.
- 공통 헤더 하나, 고정 위치와 메뉴 5개 이동/오프셋, 모바일 햄버거.
- ABOUT ME 이미지·벡터·아이콘 로딩. 프로필 슬롯 823×1159 및 원본 텍스트 확인.
- 로고/텍스트 세로 중심 일치, 왼쪽 이동 약 26px/s, Hover 정지·벗어남 재개.
- Web Animations API로 실제 CSS 애니메이션의 반복 경계 전후를 검사. 같은 화면 항목 좌표 차이 약 **0.052px**, 트랙 사이 gap **78.5px**. 시각적으로 끊김 없는 반복 확인.
- 너비 변경 시 트랙이 화면보다 넓고, 로고 129×129 및 간격 유지. 모바일 가로 넘침 없음.
- reduced-motion에서 반복 애니메이션 없음.
- 보호 대상의 기존 브라우저 회귀 검사: TOP Hover/복귀, 푸터 4개 팝업/취소/ESC/배경 클릭/포커스 복구, GitHub 새 탭, 카드 4개의 설명·실제 상세 연결·복귀, 모바일 터치 통과.
- JavaScript 오류 및 로컬 리소스 HTTP 오류 없음.
